# 实现顺序

1. 数据层：模型容量/估算系数、压缩上下文/覆盖范围、工具结果记录；取消加载时截断，成功事务提交游标。验证 120 条未读、保存失败、重启隔离。
2. 执行层：全输入计数和输出预留；Eino reduction 后接按预算分块的 summarization；当前任务/最新要求保留，AfterAgent 捕获结果供成功事务保存。验证单条超长历史、工具增长、失败、真实模型。
3. 工具层：关键词搜索、按消息回查、前后文、分页、当前会话/角色作用域。验证中文、字面 %/_、长消息续读、Eino 实际调用。
4. 界面与文档：模型高级设置增加容量；上下文整理通过实时事件更新现有回复进度，结束和停止时清除；检查原生及窄窗口，跑 Go/前端回归，记录真实验证结果。
