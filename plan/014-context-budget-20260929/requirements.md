# 需求与验收

实现用户指定的三点：按模型 Token 预算管理全部输入；接入 Eino reduction/summarization 并持久化；提供当前会话历史查询工具。

验收以 [本期入口](README.md) 的场景为准。重点是不存在固定条数截断造成的未读空洞，最新要求和任务状态不被摘要替代，失败不提交处理位置，成功摘要重启后复用。所有聊天原文仍在 SQLite，工作目录不生成历史副本。模型容量只是一个高级设置，不添加会话级调参开关。

整理上下文时，在现有回复进度位置显示“正在整理聊天上下文…”，结束后恢复当前执行状态。提示不作为聊天消息保存；停止、失败或完成后不残留，切换页面再返回能恢复正在整理的状态。原生及窄窗口中提示清楚，停止按钮可达。
