# 需求与验收

用户反馈会话页信息过多、杂乱。沿用现有视觉风格与协作行为，调整信息层级。

1. 默认不展示成员编号、工作目录说明、资料格式说明、技能历史和长篇当前任务；主页面保留标题、模式摘要、成果入口、聊天与输入。
2. 会话详情抽屉集中资料、工作目录、文件成果、成员设置、当前任务与技能记录，支持关闭、Esc与点击遮罩返回聊天。
3. 输入框保留添加资料入口和发送操作；选用历史版本时仍能看见修改基础并取消。
4. 验收原因放进验收记录，工具调用按需展开；等待补充、运行状态、停止和失败重试保留。
5. 使用已有会话验证资料预览、目录浏览、成果阅读和窄窗口布局；不改变模型调用、数据内容及版本语义。

## 后续反馈：消息关系与直接添加文件（0.1.14）

- 借鉴 Codex 的轻量对话布局，保留同席原有配色。用户消息在右侧，Agent 回复在左侧，头像及名称明确标识发言者。
- 「添加文件」直接打开系统文件选择器；取消不提示错误，成功或失败在按钮附近反馈。网页添加和资料管理仍在详情中。
- 按已保存的 replyToMessageID 展示「回复谁 + 原文摘要」，点击定位并高亮原文；不将相邻消息猜作回复对象。执行中的回复使用自身触发消息。
- 验收：带队群聊、私聊和窄窗口均能区分发言者；引用定位准确且不会立即被自动跟随拉回底部；导入、取消及已有资料查看正常。

## 后续反馈：全局细节与应用图标（0.1.15）

- 移除常驻「本地已就绪」；模型导航的绿点只代表已有配置，不代表实测可用，移除该提示，保留模型页显式连接测试结果。
- 导航统一使用同尺寸、同线宽的 SVG 图标，技能图标与其他入口居中对齐；选中项有清晰高亮及无障碍当前页标记。
- 删除侧栏重复口号、MVP 标签和角色列表内部编号/固定能力说明；压缩顶栏与管理页标题空间，保留角色模型、技能数量及启停状态。
- 将默认 Wails 图标替换为同席四人围桌标志，保留可重建图标的源码；发布包与本机安装均包含新图标。
- 验收：四个页面与窄窗口布局正常，导航高亮即时更新；角色编辑、技能读取、模型配置及会话详情入口仍可使用；不修改现有业务数据。
