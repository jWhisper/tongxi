# 需求与验收

当前规则：0.1.10 按用户反馈移除技能版本概念，每次加载读取最新内容。

## 使用规则

- 技能页创建、导入包含 SKILL.md 的目录、编辑和启停；角色设置勾选技能，会话不重复绑定。
- SKILL.md 采用 YAML 头部 name/description 与 Markdown 正文。未知头部字段原样保留，但不据此开放额外工具权限。复用当前 Eino 工具运行循环，适用于已接入且支持工具调用的模型。
- 同名技能不能重复创建。保存直接更新当前内容；更新时间仅用于拒绝过期编辑，不创建历史副本。页面无版本编号、历史版本或快照入口。
- 每个新 Run 的模型历史剔除旧技能调用和结果对及已结束轮次的推理字段，保留其他工具、公开回复及数据库原始记录，避免旧说明干扰按需加载最新内容。
- 普通运行先提供本角色当前技能名称、用途与ID；任务匹配时由模型调用 load_skill，参考文件再用 read_skill_resource 分页读取。无关任务不要求加载；自动匹配由模型判断，不保证每次正确。
- 主要助手额外知道成员的技能简介以便分工，不获得其他成员的技能。后台发言选择器不加载技能。
- 每次工具加载技能或读取参考文件时查询最新内容，并检查当前角色绑定与启用状态。同一运行、同一轮其他成员也读取最新内容；已发送给模型的消息不会被追溯修改。
- 实际 load_skill 成功才追加使用记录，按 Run+Skill 去重；记录技能名称、角色和时间，失败/停止运行已有读取记录保留。加载不等于技能步骤已完整执行。工具读取不能在停止后继续记录。
- 技能与文本参考存入本地 SQLite，原导入目录改变或删除不影响已保存内容，需要显式重新导入更新；与会话工作目录独立，不扫描或自动启用工作目录里的任意 SKILL.md。
- 支持 UTF-8 Markdown/TXT/CSV/JSON/YAML 参考文本；SKILL.md及单资源最多64KB，最多32份资源、合计512KB；最多20个技能/角色。导入跳过隐藏/依赖目录、scripts、符号链接、二进制文件，并提示部分内容未导入；资源路径不得越界。不执行脚本、安装依赖或扩大文件访问权限。

## 验收

1. 导入、创建、保存与启停可用；非法格式、重名、并发过期保存失败。
2. 角色绑定原子保存；无效绑定不能部分修改角色；重启保留。
3. Eino 实际先收到简介，再按需加载说明与参考；未绑定、跨角色、未激活的资源读取和停止后的加载均拒绝。
4. 同一运行和同轮成员再次加载能读取最新内容；停用或解除绑定后立即拒绝读取，已有使用记录保留。
5. 原生 Kimi、界面布局、安装与重启通过；原有数据迁移不丢失。
