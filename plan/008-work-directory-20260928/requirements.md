# 需求与验收

## 范围

- 新会话可选择已有目录；未选择则保存时自动创建独立目录。草稿阶段可调整，保存绑定后不能更换或清空；旧会话可补选一次。换目录需新建会话，目录丢失时提示恢复原路径。
- 全体成员共享目录的读取权限。按需浏览子目录、分页列出六类可读文件，读取时创建来源快照；不把整个目录正文塞入模型上下文。
- 同次 Chain 内同一路径首次模型读取后固定快照，后续成员/重试读取一致；新请求重新读取文件可建立新快照。界面预览不计为模型读取。旧版引用始终可读保存的原文。
- 后端限制相对路径，采用 os.Root 在打开时保证目录边界；跳过隐藏文件、node_modules、__pycache__ 和符号链接，拒绝非常规文件。Agent 无修改、删除工具。
- 添加文件复制到绑定目录；同名文件保留并自动编号，已在目录内的文件不重复复制。旧会话未绑定时保留原有导入行为。
- 导出默认打开工作目录「成果」子目录的保存对话框。资料格式、大小、引用与版本规则沿用第七期。

## 验收标准

1. 保存后 UI 无换目录入口；后端与数据库均拒绝更换/清空，重启保留绑定，旧会话补选后同样锁定。
2. 无需导入即可浏览目录与子目录；Agent 实际调用目录工具读出 Excel/CSV 等原文并引用。
3. 上级/绝对/隐藏路径、外部或内部符号链接不允许，取消后不能提交快照或读取记录。
4. 文件更新后下一轮读新值并形成新引用；同一轮成员仍读首次版本。源文件删除不破坏旧引用。
5. 用户添加文件不覆盖同名原件；导出默认在成果目录，取消保存不产生导出文件。
6. 旧数据迁移、完整回归、安装包、原生真实 Kimi 与重启验证通过。
