# 需求与验收

- 新会话默认 20 分钟、Token 不限；会话设置可修改。时间、Token 独立生效，0 不限，任一到限即暂停，不按发言次数退出。
- 预算按单次协作的 Chain 保存，首次 Run 开始计时；重试、重启不重置，配置变更不修改已开始的协作。两项都为 0 时仍可正常完成、因缺资料/无进展暂停、手动停止或报错。
- 所有成员、后台选人、摘要、工具迭代和重试的模型请求都记账。累计输入＋输出用于预算；缓存命中属于输入，仅作明细。
- 每次响应结算后立即持久化，流式重复 usage 不重复计费；失败和中断的已收到内容仍计入。无 usage 时估算并标记，无法识别的缓存统计显示“—”。最后一次响应可能超出 Token 阈值，到限后不再执行后续工具或请求。
- 会话详情旁展示会话累计总量、输入、输出，展开显示缓存命中和口径。原生与窄窗口检查，设置保存、重启后用量仍正确。
- 根 README 只介绍项目，开发细节单独放置。核对并使用最新稳定 Eino 及当前模型适配依赖。
