# 需求与验收

## 范围与默认假设

用户接受上一轮建议的第一项：聊天和成果展示。本期改善阅读、定位、复制与进度反馈，沿用现有配色和界面，不改变带队或自由讨论算法。

## 验收标准

1. 已完成的用户和角色消息能正确显示 Markdown 标题、强调、列表、表格、引用、代码；长表格和代码不撑破页面。
2. 消息复制保留 Markdown 原文，代码单独复制，成果「复制全文」只包含完整正文，成功/失败有反馈。
3. 主要助手的中间草稿与每轮验收默认折叠，可展开；成员发言与公开邀请保留可见，旧历史可读。
4. 会话顶部可直接打开最近一次带队任务的成果或草稿，历史任务也可独立查看；显示原始要求与自检记录。未完成、失败、停止或尚在执行不能伪装为交付通过。
5. 输入框附近说明当前发言者、带队检查状态、下一位等待关系；原停止、失败重试和草稿输入仍可用。
6. 不执行模型输出中的 HTML，不自动加载远程图片，不允许脚本/本地文件链接导航。既有流式平滑输出保持不变，完成后排版。
7. 数据与模型配置保留，重启后展示一致；无需数据库迁移。

## 不在本期

成果编辑器、跨请求自动续改、导出 Word/PDF、语法着色、文件或搜索工具、新的讨论方式。验收通过仍是主要助手自检，不增加独立评估模型。
