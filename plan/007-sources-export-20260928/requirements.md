# 需求与验收

## 范围

- 导入 TXT、Markdown、PDF、Word DOCX、Excel XLSX、CSV。仅读取用户选择的文件，资料归属当前会话；解析快照持久化，原文件移动不影响引用。
- TXT/Markdown 保留行号，PDF 保留页码，DOCX 保留段落/表格内容，XLSX 保留工作表与行号，CSV 保留记录号。PDF 不做 OCR，Excel 读取保存的值，不执行宏、不重算公式。
- Agent 默认具备列资料、分页读取资料、搜索网页、读取网页工具；主要助手与成员可共享已读取的来源。搜索摘要只作线索，必须实际读取网页正文才可作为验收引用。
- 首版公开搜索采用 Bing RSS，无额外密钥。公开网页仅 HTTP(S)，网络失败、登录墙、无正文、扫描 PDF 等返回明确失败，不伪装成功。
- 成果通过结构化来源 ID、片段序号和原文引用关联证据，正文可点击回看保存时的原文。后端检查会话隔离、读取记录与原文存在；内容是否支持结论仍需模型/人核查。
- 从选定正式版本导出 Markdown、DOCX，正文与该版一致，并附引用来源和摘录。取消保存不写文件；旧成果无引用也可导出。

## 验收标准

1. 六类文件都有内容与定位测试；错误/超限文件不留下半成品。首版每文件20MB、解析文本50万字，超限提示拆分。
2. 同会话成员读取一致；跨会话和未读资料不能伪造带队正式引用；原文不匹配拒绝。
3. 网页搜索得到真实链接，读网页保存不可变快照；失效网址/非公网地址/重定向绕过/超大响应都明确失败。
4. 续改保留旧引用，资料变化导入新快照，旧版本引用仍指向旧原文。
5. 原生界面可导入、预览、点引用，导出 V1 时不误用最新 V2；DOCX 结构、表格和中文内容可验证。
6. 旧数据迁移保留，运行停止/退出不允许迟到工具写入；自动测试、真实模型、安装和重启验证通过。
