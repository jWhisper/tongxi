# 需求与验收

## 范围

沿用现有主要助手带队。用户直接发修改要求，或补充缺失资料，系统携带已有成果继续推进。自由讨论和私聊不增加成果任务机制。

## 验收标准

1. 首次交付保存 V1；用户把预算100元改200元后生成同任务 V2，人数、时长等未变条件保持，V1仍可读。
2. 改验收条件必须声明原序号和本次用户原文依据；无依据改条件、丢失未变条件、伪造引用均拒绝。语义授权仍由模型理解，不声称独立事实验证。
3. 暂停记录完整草稿、有效约束与具体问题；重启后补资料仍能接着推进，不沿用已耗尽执行额度，也不因达到限额宣称完成。
4. 明确新话题另建任务；指向不清先询问，保留旧任务和版本。
5. 只有成功运行并交付才追加版本；失败、停止、迟到结果、重复回调不覆盖或重复发布。
6. 历史版本可阅读、比较正文改动，并作为下一次发送的基础；从 V1 恢复生成 V3，V1/V2 均保留。不得跨会话选版。
7. schema 8 迁移保留旧模型、角色、会话、消息和运行；旧完整成果可继续修改。

## 不在本期

文件读取/检索/引用/导出、自动合并并发编辑、手动富文本编辑器、跨会话成果共享。新任务和续改以当前任务为候选，不自动猜测多个未指定历史成果中的目标。
