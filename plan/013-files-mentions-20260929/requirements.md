# 需求与验收

1. 输入文件以工作目录中的实际文件为准，不为每次导入/读取保存整份快照；支持已有六种格式，按需读最新内容。
2. 添加后显示待发送附件，可预览与移除；发送后挂在该条消息上，重启后仍可查看名称与当前内容。外部文件复制一次，目录内文件直接引用；移除草稿附件不删除文件。
3. 正式成果引用保留当时的摘录与位置，文件变化或删除后仍可导出旧成果。网页及正式交付文件保留已有内容记录。
4. 输入@筛选启用成员，键盘/鼠标选择一位。点名仅该成员回复，停止尚未结束的自动协作，不改会话模式。未点名走原流程，无新增模式开关。
5. 验证文件跨会话隔离、只读证据校验、失败发送保留草稿、附件消息幂等、默认协作与点名切换、原生常规及窄窗口。

开发库按当前结构重建，先备份；原始工作目录文件不清理。不增加旧数据兼容链。
