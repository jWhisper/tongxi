# 需求与验收

目标：能保存多个模型连接；按服务商预填接入信息，在配置下方简短测试；角色不再填写 URL 或密钥。

默认按一个配置对应一个模型 ID。可添加同一服务商的不同模型，多个角色可共用配置。修改共享配置用于后续执行；已有请求保持启动时快照。测试当前表单，不要求先保存，不代表工具能力验收。

验收标准：

1. 可添加、编辑多个配置，支持 OpenAI 兼容、DeepSeek、Kimi 开放平台、Kimi Code、GLM。预设字段可修改，密钥不随预设跨地址复用。
2. 连接测试在表单下面，只发送短请求，返回成功及响应耗时或脱敏错误，不创建聊天/工具执行记录，不保存草稿，30 秒超时，退出可取消。
3. 角色只选择 model_id；实际执行使用所选配置的地址、模型和密钥。共享配置更新不影响正在进行的请求。
4. schema 7 升级到 8 后，原角色连接按地址、模型 ID、密钥引用整理；不同密钥保留独立配置，旧角色、会话、消息不丢失。
5. 密钥保存在系统凭据存储，不返回前端、不落入 SQLite；在用配置不能删除，版本冲突不覆盖，错误保存不留下新密钥。
6. 原生页面检查列表、预设、连接状态、角色选择和重启保留。既有带队、自由讨论、取消与重试回归通过。

本期不增加模型发现、用量计费、推理参数面板、云同步或新的会话模式。服务商模型 ID 会变化，预设作为可编辑起点，不代表已使用每家真实密钥验收。
