# 需求与验收

- 带队超过 13 次执行仍能继续修订并按验收标准交付；满足条件即可提前结束，连续两次成果和验收状态不变的保护保留。
- 自由讨论超过 6 次发言和 6 次选人仍能继续；没有新内容、开始重复、等待资料或用户结束时由选择器暂停。暂停不代表达成共识。
- 两种自动协作统一从第一个 Run 的 started_at 开始计时，最多 10 分钟；首次执行前的排队不扣时间，之后所有选人、工具、上下文整理、成员回复及等待都在同一截止时间内。
- 到时中止当前执行、取消尚未执行的后续工作，保留已发布消息、已保存成果和已收到的部分回复，不发布未完成回复或正式版本。显示暂停原因及发送“继续”的指引。
- 重试、重启不重置当前协作计时；用户新消息创建新的协作时间预算，结合现有任务/摘要/讨论继续。
- 页面移除固定次数用量和重试次数判断，不增加配置项。单个 Run 的超时、模型/工具迭代和工具调用限制保留。
- 不增加旧数据库兼容迁移；移除当前 schema 的计数上限，旧约束存在时明确提示备份重建。原始工作目录文件不删除。
