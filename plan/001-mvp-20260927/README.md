# 001：本地 Agent 协作 MVP

创建日期：2026-09-27。完成日期：2026-09-27。初版交付：0.1.0 本地 MVP（macOS arm64）；当前修正版：0.1.1（默认自动分工与总结，详见进度记录）。

这是同席的第一期，目标是交付一个本地桌面软件：用户能创建不同角色的 Agent，与它们聊天，也能让它们在同一会话里互相发消息，并查看、停止整个过程。

一期同时支持助手带队与多人讨论。首个演示场景采用「写作助手联系评审助手检查活动文案」；第二个场景是「大家依次讨论一次，再指定成员总结」。AgentAsTool 评审子任务作为首个后续增强，不是一期交付前提。
