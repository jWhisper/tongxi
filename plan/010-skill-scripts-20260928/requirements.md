# 需求与验收

用户先选择 Python + Node.js，随后追加 Shell。Shell 首批按 Bash 的 .sh 文件执行，不增加命令字符串输入框。

1. 管理页导入并展示 scripts/ 脚本，保留原角色绑定；更新后执行最新保存内容。
2. 角色先加载技能再自动运行脚本，参数为数组；未加载、解绑、停用和停止后拒绝执行。
3. 会话工作目录原文件只读，结果写入独立成果目录；禁止网络和继承密钥环境，缺少解释器或隔离组件明确失败。
4. 三种语言实际执行、输出文件可读；超时与停止清理子进程；输出截断不阻塞，失败保留退出码和错误。
5. 会话显示使用及执行记录，重启后保留，历史数据无丢失。

边界：当前 macOS；可信脚本；不自动安装依赖、不执行任意模型生成代码、不提供 Shell 交互终端、不增加技能版本。原导入目录变更仍需重新导入保存。
