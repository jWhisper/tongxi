# 需求与验收

用户确认上一轮建议，实施文件卡片、交付前读取核对、自然语言续改与历史保留。

1. 支持现有六类可解析文档。成功脚本生成文件自动登记，聊天可预览、打开和定位文件夹，无新增配置页。
2. 文件保存不可变字节快照，归属会话、实际执行。其他成员可发现和读取；正式交付需本轮读完解析文字并给出核对依据，不以退出码代替内容检查。
3. 文件随现有成果版本保存；更新结果采用新文件ID，旧版本附件和内容不变；缺失、伪造、跨会话、未读完或未提供依据的文件不能正式交付。
4. 用户自然语言续改后生成更新文件并交付同一任务的新版本；暂停和失败不覆盖已发布版本。
5. CSV → 生成统计文件 → 评审读取 → 主要助手交付 → 按部门续改 → 新版交付 → 旧版仍可打开，为端到端验收。

边界：复用当前解析格式和限制；文本预览不承担原排版、OCR、图表理解和公式重算；不增加技能版本、任意代码执行或原文件覆盖。当前先用SQLite保存字节以保证快照和元数据事务一致，文件上限20MB、每次64MB，后续大量文件场景再评估存储。
