# 同席 · Tongxi

让你的 AI 伙伴一起交流、一起做事。

同席是一个本地桌面 AI 协作工具。你可以创建不同分工的角色，选择各自使用的模型，再邀请他们围绕同一件事讨论和协作。

- **助手带队**：主要助手按需邀请伙伴、检查验收条件，逐步完善并交付成果。
- **自由讨论**：伙伴根据话题补充观点、提出质疑，也可以通过 `@` 点名回应。
- **持续修改**：围绕已有成果继续调整，保留交付版本和修改记录。
- **使用资料与技能**：读取会话工作目录中的文件、查找网页，按需加载角色绑定的技能并执行脚本。
- **自选模型**：支持 OpenAI 兼容接口，以及 DeepSeek、Kimi、GLM 等服务商。

角色、会话和成果保存在本机；使用在线模型时，相关上下文会发送给所选服务商。项目仍在开发中，目前主要在 macOS Apple Silicon 上使用和验证。
